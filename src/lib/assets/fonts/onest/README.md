# Onest

Variable WOFF2 files for weights 400–800, with Latin and Latin Extended subsets.
Served locally through Vite; body and control text use `--font-body`.

Source: [Google Fonts](https://fonts.google.com/specimen/Onest), Google Fonts CSS
API version 11. Original project: [simpals/onest](https://github.com/simpals/onest).
The SIL Open Font License is included in `OFL.txt`.
