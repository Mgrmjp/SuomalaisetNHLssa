# Test locations

The default Vitest suite lives under [src/lib/tests](../src/lib/tests/), using [vitest.config.js](../vitest.config.js). The test file in this top-level directory is a legacy diagnostic and is not included by the current Vitest pattern.

Use [Testing](../docs/TESTING.md) for current commands, Python suites and browser checks. Add application regression tests to the configured suite rather than assuming top-level tests run automatically.
